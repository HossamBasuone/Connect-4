🎮 Connect 4 Game

A fun and interactive two-player Connect 4 game built using HTML, CSS, and JavaScript. The game features a responsive design, score tracking, and automatic win detection.

✨ Features
🎯 Interactive 8×8 game board
🔴 Two-player gameplay (Red vs. Blue)
🏆 Automatic win detection (horizontal, vertical, and diagonal)
🤝 Draw detection
📊 Score tracking for both players
🔄 New Game and Reset Scores buttons
📱 Responsive design for mobile and desktop
🎨 Modern UI with gradients and animations
🛠️ Technologies Used
HTML5 — Game structure
CSS3 — Styling, animations, and responsive layout
JavaScript — Game logic, player turns, win detection, and score management

🎮 How to Play
Open the game in your browser.
Red plays first, followed by Blue.
Click any column to drop your piece.
Connect four pieces horizontally, vertically, or diagonally to win.
Click New Game to start another round while keeping the scores.
Click Reset Scores to clear the scores and start fresh.
🚀 Getting Started
Clone or download this repository.
Make sure these files are in the correct locations:
index.html
style.css
js.js
OIP.jpg (favicon)
Add your screenshots to the screenshots folder.
Open index.html in your web browser.
Enjoy the game!
